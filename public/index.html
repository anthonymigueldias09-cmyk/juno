Claude Code sem login — direto pelas suas API keys

O Claude Code respeita as variáveis ANTHROPIC_BASE_URL, ANTHROPIC_AUTH_TOKEN, ANTHROPIC_MODEL e ANTHROPIC_DEFAULT_{HAIKU,SONNET,OPUS}_MODEL. O Juno cria um servidor local que fala “Anthropic” e traduz para o provedor que você escolheu. Assim ele nunca pede login na Anthropic: usa a key que está aqui no painel.

1) Modo pontual (recomendado)

Rode no terminal — o Claude Code abre normal (mesma interface do PowerShell/CMD), já conectado ao provedor ativo:

juno claude

2) Comandos manuais (sem o juno)

3) Modo persistente

Grava as variáveis em ~/.claude/settings.json (com backup). A partir daí, o comando claude comum já sai usando o Juno. Desfaça quando quiser.

Servidor

Depois de mudar porta/host, reinicie: juno stop e juno.

Segurança

As API keys ficam em (fora do repositório). O token do Claude Code autentica as chamadas locais.
